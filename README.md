- Automated late-submission deductions and SPI calculations using Hangfire.
- Performance analytics, grade distribution reports, and PDF/Excel exports.
- JWT authentication, BCrypt password hashing, and SMTP email notifications.

**Tech:** React, .NET 10, SQL Server, Hangfire, Bootstrap

- Recurring bill and subscription processing with Hangfire.
- Financial analytics and overspending warnings.

**Tech:** React 19, .NET Core, SQL Server, Tailwind CSS, Hangfire, PWA

- SQL Server integration and real-time analytics.

**Tech:** React 19, FastAPI, XGBoost, Scikit-learn, Tailwind CSS
